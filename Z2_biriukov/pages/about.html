WEBTE1 · ZADANIE 2

O projekte

Obedové menu troch podnikov pri FEI STU s výberom dňa, týždenným prehľadom a filtrami reštaurácií.

Dáta a aktualizácia

Fetch API načíta HTML a samostatné parsery cez DOMParser a DOM selektory vyberú dni, dátumy, jedlá, ceny, porcie a alergény. Zobrazujú sa iba textové údaje; chyba jedného zdroja neovplyvní ostatné menu.

Predvolene sa používajú lokálne HTML kópie bez proxy. Priame webové zdroje môže blokovať CORS. Dáta sa ukladajú do localStorage osobitne pre oba režimy; nové načítanie spustí „Aktualizovať menu“. Pre novú lokálnu ponuku treba nahradiť aj HTML kópie.

Čas aktualizácie označuje načítanie do aplikácie. Dátumy menu sa preberajú zo zdrojov bez odhadovania chýbajúcich údajov.
